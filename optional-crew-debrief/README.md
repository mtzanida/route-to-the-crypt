# Optional Kiro Crew Debrief

This folder documents a possible stretch feature. The intended Kiro Crew application should be developed and submitted from its own public GitHub repository if pursued.

It consumes a JSON snapshot exported by the main app and returns a short educational debrief. It must not modify routing state, require AWS credentials, or be needed to launch or use Route to the Crypt.

Build only after the core project is complete. If the Crew SDK or local setup causes friction, skip this bonus and keep the main app unchanged.
