# Design — Route to the Crypt

## Main screen

- Header: product name, short purpose, clear “educational model” label.
- Left rail: curated scenario cards and difficulty tags.
- Center: region/endpoints visualization with a highlighted illustrative path.
- Right rail: endpoint health controls and outcome explanation.
- Footer: assumptions, AWS source links, and export JSON action.

## Visual direction

Dark charcoal control-room surface, parchment text, muted violet and amber accents, restrained ghost imagery, and one clear status color system. Avoid relying on color alone for health or route status.

## Optional Crew feature

Crew Debrief is an independent Kiro Crew app that consumes the versioned JSON export. It returns a short, optional learning debrief. It does not change scenario state and the core app never waits for it.
