# AWS evidence and claim boundaries

- This project is a learning model, not a simulator certified by AWS.
- Do not claim behavior is exact unless the corresponding scenario rule has been checked against current official AWS documentation.
- Add source links beside scenario explanations.
- Distinguish documented AWS behavior from the app's simplified visualization.
- Do not claim live tests, production deployments, or observations from a real AWS application. None are part of this project.
- If a rule is uncertain, simplify the scenario or label the uncertainty instead of guessing.
