# Product steering

Build Route to the Crypt for AWS learners and cloud engineers who want to reason about routing scenarios in a safe, visual environment.

- Make the primary learning flow understandable without AWS credentials, accounts, or network access.
- Keep the core application complete without Kiro Crew.
- Treat the haunted aesthetic as visual storytelling; preserve readability and accessibility.
- Prefer a small number of complete scenarios over a broad but shallow feature list.
- State what the model does and does not represent wherever a learner could mistake it for production behavior.
